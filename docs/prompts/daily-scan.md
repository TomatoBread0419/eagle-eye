# 每日扫描 Prompt 模板 (伪示例)

> 每日 08:00 BJT 执行的 GARP 动量扫描。由 Hermes Cron 定时触发。

---

## 任务：GARP 动量扫描

### 背景

当前时间：{time_bjt} BJT
市场状态：{market_status}

### 输入数据

1. 加载候选池（~87 只股票池，按板块分类）
2. 获取实时价格（qt.gtimg.cn）
3. 读取板块事件偏置（market_events_latest.json）
4. 读取历史持仓（避免推荐近期止损的股票）

### 评分维度

对每只候选股票从以下维度评分（0-100）：

| 维度 | 权重 | 说明 |
|------|------|------|
| 5日动量 | 20% | 短期趋势（上涨趋势得分高） |
| 20日动量 | 15% | 中期趋势 |
| RSI | 10% | 40-65 之间最佳 |
| 成交量 | 10% | 放量上涨加分 |
| 板块偏置 | 15% | 板块事件方向（利好加分） |
| 相对强度 | 10% | vs SPY |
| ATR 波动率 | 5% | 高波动加分（用户投机风格） |
| 估值 | 10% | PE/G 合理加分 |
| 流动性 | 5% | 日均成交量足够 |

### 输出要求

```json
{
  "scan_time": "ISO时间",
  "market_mode": "趋势/震荡/风险",
  "top_candidates": [
    {
      "ticker": "股票代码",
      "score": "综合评分 (0-100)",
      "sector": "板块",
      "rank_in_sector": 1,
      "rationale": "AI 判断理由（≤150字）",
      "suggested_action": "buy / watch / pass"
    }
  ],
  "excluded": [
    {"ticker": "代码", "reason": "排除原因"}
  ]
}
```

### 特殊规则

1. 跳过 #1-#2 板块龙头（用户投机风格，偏好 #3-#5）
2. 跳过过去 30 天内止损过的股票（用户反感反复横跳）
3. 中小盘优先（市值 < 500亿）
4. 每个板块最多 2 只候选
