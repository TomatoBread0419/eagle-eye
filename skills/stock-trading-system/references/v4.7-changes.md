# v4.7 变更记录 (2026-06-13)

## 虚假回撤卖出 Bug 修复

### 症状
`--stops` 触发虚假止盈卖出。DDOG 实际回撤 0.7%，报告声称 15.9%。
同时错误触发 IBM/MU/SNOW/WMT/XOM 共 6 笔卖出，合计 $13,807。

### 根因
`us_trader.py` `analyze()` 函数第352行使用 `max(highs[-20:])` 计算回撤基准。
日内最高价可远高于收盘价（DDOG 最高 $237.56 vs 收盘 $228），
导致回撤计算严重失真。

### 修复（双层防护）

**一层：数据源修正**
```python
# 修复前
recent_high_20 = max(highs[-20:]) if len(highs) >= 20 else max(highs)

# 修复后
recent_high_20 = max(closes[-20:]) if len(closes) >= 20 else max(closes)
```

**二层：state 验算**
`stops_mode()` 内，analyze 返回"回撤卖出"信号后，
用 `get_highest(sym, state)` 复算实际回撤。
若实际回撤 < `TP_DRAWDOWN_PCT * 100 * 0.5`（即阈值一半），
则清除卖出信号并记录 `_suppressed_sell`。

### 验证
2026-06-13 跑 `--stops` 拦截了5个虚假信号：
- DDOG: 报告回撤 15.9% → 实际 3.2%
- PANW: 报告回撤 8.5% → 实际 2.0%
- MU: 报告回撤 8.2% → 实际 1.2%
- WMT: 报告回撤 8.1% → 实际 ~0%
- XOM: 报告回撤 8.4% → 实际 3.0%

## 止损覆盖自动审计

`stops_mode()` 末尾新增自动审计步骤：
1. 重新拉 holdings（止盈可能改变了持仓）
2. 拉 open orders
3. 计算 `protected = {stop_syms} | {open_sell_syms}`
4. 缺失保护 → 用波动率分档补挂 stop order

防止 AI 手动发现 AMD/ARM 缺失止损的场景重复发生。
