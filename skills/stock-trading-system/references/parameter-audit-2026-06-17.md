# 参数审计 (2026-06-17)

## 概况

整个鹰眼系统有 132 个硬编码参数,分散在4个文件:
- ai_weight_config.json: 68个评分参数
- us_trader.py: ~15个止损/回撤/仓位参数
- us_screener.py (kelly): ~8个凯利参数
- us_common.py: ~5个指标参数
- 其余分散在各脚本

## 分类

| 类别 | 数量 | 状态 |
|------|------|------|
| 应随市场状态变化 | ~15个 | 全部硬编码 |
| 应随历史表现校准 | ~70个 | 全部拍脑袋 |
| 应随标的特征差异化 | ~20个 | 全部一刀切 |
| 应随绩效反馈调整 | ~10个 | 全部无反馈 |
| 真正固定合理的 | ~17个 | OK |

## v6解决方案

calibrator.py 每周六自动校准:
1. sigmoid参数(k, midpoint) — 用实际score vs 涨跌拟合
2. ATR→赔率映射 — 用实际盈亏比拟合
3. 止损分档边界 — 用被止损标的后续走势反推
4. 板块加分 — 用板块实际贡献调整
5. 评分权重 — 用滚动窗口验证预测准确率

无校准数据时(如刚启动),所有系统回退到默认参数。
