# 事件感知的板块再平衡：伊朗协议 + 能源缺口案例（2026-06-15）

## 场景

**板块缺口**：持仓能源为0%，目标配置3%，缺口 $3,068。

**事件**：美伊和平协议签署 → 霍尔木兹海峡开放 → 原油暴跌5%至三个月新低 → CVX跌约4%。

**机械决策 vs 事件感知决策**：

| 维度 | 机械再平衡（错误） | 事件感知决策（正确） |
|------|-----------------|-------------------|
| 看到缺口 | 能源缺$3,068 → 买能源 | 能源缺但原油崩5% → 不买 |
| 理由 | 缺口越大加分越多 | 伊朗协议=供给增加=油价下行，买是抄下跌飞刀 |
| 扫描器结果 | 能源股不在TOP20（分数已低） | 分数低 + 事件利空 = 双重过滤 |
| 结果 | 追跌 | 等待油价企稳后再评估 |

## 决策原则

事件优先级高于机械缺口。即使配置模型说"能源缺3%"，如果对应板块正在发生重大利空事件，延迟建仓是正确选择。

三个条件**同时满足**时才应忽略事件进行机械再平衡：
1. 缺口持续时间 >2周（不是短期事件窗口）
2. 事件冲击是一次性的（不是趋势性变化）
3. 其他同缺口板块无事件利空

**Iran deal的能源冲击属于趋势性变化** — 霍尔木兹海峡长期开放 = 供应端持续性增加。需要等待新均衡价格出现后再评估。

## 同类场景

事件感知应覆盖机械缺口的情形：
- **关税/贸易战** → 对应板块（进出口敏感）推迟补仓
- **战争/和平协议** → 国防/能源板块等待方向确认
- **FOMC前夕** → 所有板块2天内不宜新开仓（波动不确定）
- **行业监管突变** → 对应板块立即暂停操作
- **黑天鹅（如AI泡沫破裂）** → AI/SaaS板块评估传染风险
