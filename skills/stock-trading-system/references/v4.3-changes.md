### 量价关系四象限

| 价格 | 量比 | 信号 | 评分 | 含义 |
|------|------|------|:---:|------|
| ↑ | >1.2x | bullish 📈放量上涨 | +3 | 强势趋势确认 |
| ↑ | <0.8x | divergence ⚠️缩量虚涨 | -3 | 假突破，量价背离 |
| ↓ | >1.2x | bearish 📉放量下跌 | -2 | 主力出货 |
| ↓ | <0.8x | neutral | 0 | 正常回调 |
| — | >2.0x | spike 🔥 | 标记 | 异常放量，关注 |
| — | <0.5x | dry 🏜 | 标记 | 极度缩量，关注 |

### 集成位置

- **us_screener.py `_scan_one()`**: 成交量评分 ±3 分，信号标记到 vol_signal 字段
- **us_trader.py `analyze()`**: 成交量确认 buy_score ±2 分，信号记入 buy_reasons

## 2. 板块内排名

### 计算逻辑

在 `scan()` 中，全局排序后：

```python
sector_ranked = {}
for r in results:
    sector_ranked.setdefault(r['sector'], []).append(r)
for sec, stocks in sector_ranked.items():
    stocks.sort(key=lambda x: x['momentum_score'], reverse=True)
    for i, r in enumerate(stocks):
        r['sector_rank'] = i + 1       # 板块内排名
        r['sector_total'] = len(stocks) # 板块总数
        r['sector_leader'] = i < 2      # 前2名标记
```

### 用户交易哲学（2026-06-10 确认）

> "如果是前一二的基本就代表没什么增值空间了"

规则：
- 板块 #1-2（👑龙头标记）→ 大概率在高位，增值空间有限

- 板块末位 + 成交量放大 → 可能反转

## 3. 性能优化: vol_map 复用

### 问题

`update_trail_stops()` 原本对每只持仓独立调用 `__get_volatility()` → Alpaca API，但 `analyze()` 已经拿过同样的 K 线数据。

### 修复

1. `analyze()` 返回 `vol_20d` 字段（已有 closes，零额外成本）
2. `update_trail_stops()` 新增 `vol_map` 参数
3. 三个入口 (`stops_mode`, `main`, `report_mode`) 从 `all_results` 构建 `vol_map` 传入

```python
vol_map = {r['symbol']: r.get('vol_20d') for r in all_results if r.get('vol_20d') is not None}
trail_msgs = update_trail_stops(holdings, state, existing_stops, vol_map=vol_map)
```
