# Eagle Eye V7.1.1 — Operations Push Policy V1.1

**Effective:** 2026-06-18
**Freeze:** 14-day Observation Mode (Bug fixes only)
**Override:** Takes precedence over earlier notification formats.

---

## 1. Heartbeat (Hourly)

Confirms system is alive. Exactly 6 fields, no more.

```
🦅 Eagle Eye Heartbeat
YYYY-MM-DD HH:MM
system=ONLINE
health=GREEN|YELLOW|RED
scheduler_state=RUNNING|IDLE|DELAYED
executor_state=READY|MARKET_CLOSED|NOT_REQUIRED|RUNNING|ERROR
runtime_reason=MARKET_CLOSED|WEEKEND|HOLIDAY|NO_SIGNAL|NO_ACTION_REQUIRED|TRADING_ACTIVE|DEGRADED_MODE|EMERGENCY_STOP
checks=DNS=OK|FAIL | API=OK(OPEN|CLOSED)|FAIL | DB=OK|NODASH
```

**Forbidden:** UNKNOWN, never, raw minutes (208m), scheduler_last_run, executor_last_execution, orders, dashboard.

---

## 2. Dashboard (Per AI Decision Cycle)

```
🦅 Eagle Eye Dashboard
Active Sectors=N
Exposure=X%
Actions Required=N
Trade Intent=BUY|SELL|HOLD SYM [xQTY]
Policy Status=PASS|REJECT
```

**Forbidden:** Full holdings list, sector breakdown, scanner raw data.

---

## 3. Scheduler Receipt (Key Job Completion)

Only for: AI_DECISION, MARKET_ENV, SIGNAL_DECAY, HEALTH_CHECK, WEEKLY_CALIBRATION.

```
🕒 Eagle Eye Scheduler
job=AI_DECISION
status=SUCCESS|FAILED
[duration=Xs]
[reason=ERROR_TEXT]
```

**Forbidden:** relay, watchdog, heartbeat, notification, cleanup, backup jobs.

---

## 4. Alert (Exception Only)

**WARNING (≤60s):** ENTER_DEGRADED, EXIT_DEGRADED, TRADING_LOCK, DATA_STALE, API_FAILURE_SPIKE, DELAYED_JOB
**CRITICAL (≤60s):** EMERGENCY_STOP, SYSTEM_OFFLINE, DATABASE_CORRUPT, EXECUTOR_CRASH

```
📡 Eagle Eye Alert
🟡|🔴 [LEVEL] EVENT
   Time: YYYY-MM-DD HH:MM:SS
   key: value
```

Critical events use fast-path (critical_delivery.json → relay priority processing).

---

## 5. Daily Message Budget

- Normal: 10-15 messages/day
- Hard cap: 20 messages/day
- Budget exceeded → heartbeat suppressed (silent)
- Alerts exempt from budget
