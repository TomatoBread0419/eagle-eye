# v4.4 变更记录 (2026-06-10)

## 新增指标

### MACD 金叉/死叉 (`calc_macd`)
- 文件: `us_common.py`
- 返回: `(macd_line, signal_line, histogram, crossover)`
- crossover: `'golden'` (金叉) / `'death'` (死叉) / `None`
- 扫描器: 金叉 +3, 死叉 -2, 零轴上方 +1
- 交易器: 同逻辑加入 `analyze()`
- 信号标记: 🔱金叉 / ☠️死叉

### ATR 平均真实波幅 (`calc_atr`)
- 文件: `us_common.py`
- 返回: 美元金额（如 ATR=$12.50）
- 不直接加减分，用于仓位计算和止损精度
- 存储在 result dict 的 `atr` 和 `atr_pct` 字段

### RS vs SPY 相对强度
- 文件: `us_screener.py scan()`
- 拉取 SPY 日K线（1次API），计算 1月/3月基准收益
- 股票收益 - SPY收益 = 相对强度
- RS_1m > 5% → +2, RS_1m < -5% → -2
- SPY 数据不足时（IEX免费层可能不支持SPY）优雅跳过
- 信号标记: RS+N% / RS-N%

### 市场事件 → 板块映射 (`load_sector_event_bias`)
- 文件: `us_screener.py`
- 双重来源:
  1. `position_impact` 中的 🔴/🟢 按板块汇总（标的→板块→信号计数）
  2. `events[].sector_impact` 直接指定板块影响
- 最高 +3（利好）/ 最低 -3（利空）
- 信号标记: 📰利好+N / 📰利空-N

### 持仓相关性 (`calc_correlation`)
- 文件: `us_common.py`
- 皮尔逊相关系数，纯计算
- 用途：检测假分散（持有20只但全是tech → 相关性>0.7）
- 下一步：集成到 `us_report.py` 输出

## 已知限制

- **SPY 基准**: Alpaca IEX 免费层可能不包含 SPY 数据，此时 RS 对比跳过
- **yfinance**: Yahoo 对中国 IP 限流，`get_yf_metrics()` 返回空 dict
- **板块事件映射**: 依赖 cron 生成的 `market_events_latest.json` 有数据
