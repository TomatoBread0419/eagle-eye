# v4.6 代码审计 & Bug 修复 (2026-06-10)

全量代码审计：us_common.py / us_screener.py / us_trader.py / us_portfolio.py

## 发现的 Bug 及修复

### Bug 1 (严重): 3月动量是死代码

**根因**: `get_daily_bars()` 硬编码 `limit=60`（URL 参数），而 `_scan_one()` 调 `__get_daily_bars(sym, 60)`（days=60 日历天 ≈ 42 交易日）。`ret_3m` 需要 64 根日K → n>=64 永远 False → ret_3m 始终 None。

**修复**:
- `get_daily_bars()`: 新增 `limit` 参数（默认 70），URL 内使用该参数
- `_scan_one()`: `__get_daily_bars(sym, 100)` — 100 日历天 ≈ 70 交易日
- ret_3m 加兜底：`n >= 42` 时用一半窗口 (`closes[21]`)

**影响**: 13 维度评分中权重 25% 的维度无声无息地不工作。

### Bug 2 (严重): RSI 超买罚分双重扣分

**根因**: 两个独立 `if` 而非 `if/elif`：
```python
# 旧代码
if rsi14 > normal_threshold: score += -10
if rsi14 > extreme_threshold: score += -20  # RSI=87 → -30!
```

**修复**: 极端阈值先检查 → `elif`：
```python
if rsi14 > extreme_threshold: score += -20
elif rsi14 > normal_threshold: score += -10
```

### Bug 3 (严重): stale highest 毒化追踪止损

**根因**: `set_highest()` 用 30% 价格偏离启发式检测新仓位。平仓→以相近价格重新开仓同一标的时，`abs(price - old_entry)/old_entry < 30%` → 不重置 highest。旧 highest 远高于新成本 → 追踪止损线高于现价 → 触发误卖。

**修复**: 直接比较 `stored_cost != cost`，成本变化立即重置：
```python
if stored_cost != cost:
    pos['highest'] = max(price, cost)
    pos['entry_cost'] = cost
    pos['trail_trigger'] = 0
    return
```

### Bug 4 (严重): 持仓报告止损距离用 5%

**根因**: `us_portfolio.py` 第 166 行 `stop_price = cost * 0.95`，系统其他部分已升级到波动率分档 7-10%。

**修复**: import `get_volatility_stop_pct`，用 `stop_price = cost * (1 - get_volatility_stop_pct(None))` → 默认 8%。

### Bug 5 (严重): main() 忽略 --mode 参数

**根因**: `main()` 不接受 mode 参数，第 790 行 `check_position_utilization(..., mode='cautious')` 硬编码。`args.mode` 只传给 `report_mode()`。

**修复**: `main(mode='normal')`，`__main__` 中 `main(mode=args.mode)`。

### Bug 6 (中等): MACD 信号线计算偏离标准

**根因**: `calc_macd()` 信号线只对最后 9 个 MACD 值做 EMA，标准 MACD 是对全序列做 EMA。

**修复**: `signal_ema = ema(macd_series, signal)`（全序列）。

### Bug 7 (中等): report_mode 的 target_util 参数未使用

**根因**: `report_mode(mode, target_util)` 接受 target_util 但从未传给 `check_position_utilization`。

**修复**: `check_position_utilization` 新增 `target_util_override` 参数；`report_mode` 传入。

### Bug 8 (小): get_us_price 裸 except

**根因**: `except: pass` 吞所有异常包括 KeyboardInterrupt。

**修复**: `except Exception: pass`

## 审计方法论（复用模板）

1. **数据窗口匹配**: 每个计算需要的 bar 数 vs API 实际返回数，逐行对账
2. **if/elif vs if/if**: 扫描所有连续的阈值判断，检查是否有叠加扣分/加分
3. **跨模块一致性**: 同一定义（止损%、板块映射）是否在多处重复且不同步
4. **参数传递链路**: 从 CLI args → 函数签名 → 内部调用，检查参数是否在每一层都被使用
5. **状态残留**: 持久化状态（risk_state.json）中是否有字段在仓位变化后不会自动清理
