# 扫描器调整记录（2026-06-08）

## 微信 session 中发现的问题

用户在微信 session 中问"扫描器需不需要调整"，AI 分析了4个短板：

1. **纯动量评分，不看基本面**
   - 公式：1月涨幅×0.5 + 3月涨幅×0.3 + 短期涨幅×0.2 - RSI罚分
   - 问题：追涨杀跌，容易买到顶部

2. **缺少关键板块**
   - 没有能源股（伊朗以色列冲突 → 油价受益股扫不到）
   - 没有军工股（Lockheed Martin、Raytheon 直接受益于战争）
   - 没有资源股（钨、稀土、锂）
   - 没有防御性高股息股（公用事业、REITs）

3. **市场叙事是"防御"但扫描器不调整**
   - 大盘暴跌10%时，扫描器还是按同一个逻辑选动量最强的股
   - 应该在防御模式下提高买入门槛、偏好低波动/高股息标的

4. **候选池太偏科技**
   - 70只里30只是科技/AI，大盘跌的时候科技首当其冲

## 解决方案

### 短期（已实施）
- 新增 8 只股票：能源（XOM/CVX/COP）、军工（LMT/RTX/NOC）、资源（FCX/NEM）
- 防御模式 RSI 门槛从 75 降到 65

### 中期（已实施）
- 评分公式加入波动率因子（20日年化标准差）
  - 低波动(<20%) +3，高波动(>50%) -3
- 防御模式板块加分
  - telecom/defense +5，energy +4，pharma +3
  - tech -2，ai -3
- 板块缺配加分（读 us_portfolio.json）
  - 缺口>3% → +5，缺口>2% → +3，缺口>1% → +2

## 验证结果

dry-run 通过（78只扫描，77只成功）：
- LMT（军工）登顶 #1 — 防御板块加分生效
- 能源股 CVX/COP/XOM 进 TOP20
- 高波动 SNOW(142%)/MU(121%)/ARM(123%) 被惩罚
- 低波动 PFE(19%)/MCD(19%)/LIN(18%) 防御模式下排名靠前
