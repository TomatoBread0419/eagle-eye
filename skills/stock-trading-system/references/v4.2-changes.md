# v4.2 变更记录 (2026-06-10)

## 1. 波动率分档止损（替代一刀切 5%）

**动机**: 一刀切 5% 止损对稳定股票太宽、对高波动股票太窄。SNOW (142% vol) 跟 KO (15% vol) 用同一个 5% 不合理。

**实现**: `get_volatility_stop_pct(vol_20d)` in `us_common.py`

| 20日年化波动率 | 止损百分比 | 典型股票 |
|---|---|---|
| <20% | 7% | KO, MCD, LIN |
| 20-35% | 8% | AAPL, JPM, MSFT |
| 35-50% | 9% | CAT, GS, WMT |
| >50% | 10% | SNOW, DDOG, AMAT |
| 未知 | 8% (默认) | 新股/数据不足 |

**受影响文件**:

- `us_common.py`: `+calc_volatility()`, `+get_volatility_stop_pct()`
- `us_trader.py`:
  - `update_trail_stops()`: 每只持仓实时计算波动率 → 选择止损档位
  - `get_trail_stop(sym, state, cost, vol_20d=None)`: 新增 vol_20d 参数
  - `report_mode()`: `stop_status` 输出新增 `vol_20d` 和 `stop_pct` 字段
  - 移除全局常量 `STOP_LOSS_PCT=0.05` 和 `TRAIL_DISTANCE=0.05`
  - 新增 `DEFAULT_STOP_PCT=0.08` 和 `DEFAULT_TRAIL_PCT=0.08`
  - 新增 `__get_volatility(symbol)` 包装函数
- `us_screener.py`: 移除本地 `calc_volatility()`（改从 `us_common` 导入）
- `us_risk_state.json`: `hard_stop_pct` / `trail_stop_pct` 从 `0.05` 改为 `"tiered_7_10_by_volatility"`

**验证**: `--stops` 模式在真实 30+ 持仓上运行正常，日志显示各股票按波动率正确分档。

## 2. yfinance 基本面评分

**动机**: 纯技术面扫描缺少估值和风险维度。加入 beta / PE / 股息率作为 GARP 因子。

**实现**: `get_yf_metrics(symbol)` in `us_common.py`

| 指标 | 条件 | 加分 |
|---|---|---|
| Beta | >2.0 | -2 |
| Beta | >1.5 | -1 |
| Beta | <0.5 | +1 |
| Forward PE | >50 | -2 |
| Forward PE | 10-25 | +2 |
| Forward PE | 25-35 | +1 |
| 股息率 | >2% | +1 |

**优雅降级**: `get_yf_metrics()` 在 yfinance 未安装或网络不通时返回 `{}`，不影响扫描器正常运行。`pip install yfinance` 即可激活。

**受影响文件**:

- `us_common.py`: `+get_yf_metrics()`
- `us_screener.py`:
  - `_scan_one()`: 波动率因子之后插入 yf 评分块
  - 结果 dict 新增 `yf_score` 和 `yf_details` 字段
