# v4 架构重构记录 (2026-06-08)

## 重构背景

用户明确要求：
- "这样是硬约束，我们应该智慧去判断"
- "还是有差距的时候，我是在这支股票上加仓，还是再挑一支？我们要自己智慧去判断"
- "防御模式是系统根据市场事件自动判断的，不是你的偏好。我要激进模式！"

## 核心变化

| 维度 | v3 | v4 |
|------|-----|-----|
| 决策者 | 脚本 if-else | AI LLM |
| 买入逻辑 | 硬约束"至少买1笔" | AI 判断买什么/买多少 |
| 模式判断 | 脚本读 narrative 自动判断 | AI 根据事件影响判断 |
| 仓位目标 | 脚本根据 narrative 设定 | AI 自己定（0.30-0.70） |
| 信息利用 | 只用扫描器+事件模式 | 全量信息综合 |
| 板块平衡 | 无 | 持仓分析→缺配加分 |
| 加仓 vs 开新仓 | 无逻辑 | AI 智慧判断 |
| 止损/止盈 | 机械执行（保留） | 机械执行（保留） |
| 安全阀 | 硬约束（保留） | 硬约束（保留） |

## 保留的安全阀（机械，AI 不可覆盖）

- 回撤 >12%：暂停买入
- 回撤 >20%：减半仓
- 硬止损 5%：Alpaca stop order（不取消）
- 追踪止损 5%：软件层动态追踪
- 阶梯止盈 20%/35%：机械执行
- 单笔买入不超过现金 15%
- sell→buy 配对：AI 决策买什么，但卖出后必须买回
