# Alpaca 真实账户手续费（2026）

| 项目 | 费用 |
|------|------|
| 股票/ETF 买卖 | **$0 佣金** |

## 出入金

| 通道 | 费用 | 到账时间 |
|------|------|---------|
| ACH（美国银行） | 免费 | 1-3工作日 |
| 国际电汇（SWIFT）入金 | Alpaca不收费 | 1-3工作日 |
| 国际电汇出金 | Alpaca不收费 | 1-3工作日 |
| **汇丰→Alpaca SWIFT** | 汇丰收$50-150（含中间行费） | 1-3工作日 |

## 关键注意

- 零佣金 ≠ 零成本：还有买卖价差（spread）
- 国际用户开户需KYC（护照+地址证明+自拍）+ W-8BEN表格
- **中国税务居民（非HK税务居民）**：填W-8BEN，填中国身份证号作为Tax ID
- 交易时段：美东09:30-16:00（北京时间21:30-04:00夏令时）
