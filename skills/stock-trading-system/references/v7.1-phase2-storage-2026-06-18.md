## SQLite 关键配置

- **WAL 模式**：更好的并发读写性能
- **外键约束**：`PRAGMA foreign_keys=ON`
- **Row 工厂**：`conn.row_factory = sqlite3.Row`（按列名访问）
- **线程安全**：threading.local() 每线程独立连接
- **事务管理**：`with db.transaction()` 上下文管理器

## 踩坑记录

### Path 拼接错误
- `data_dir / 'backup_json_' + timestamp` → TypeError: PosixPath + str
- 修复：`data_dir / f'backup_json_{timestamp}'`
- 教训：Path 对象不支持 `+` 拼接，用 f-string 或 `/` 操作符

### import 语法错误
- `from datetime timedelta` → SyntaxError
- 修复：`from datetime import timedelta`
- 教训：写完代码立即 lint 检查
