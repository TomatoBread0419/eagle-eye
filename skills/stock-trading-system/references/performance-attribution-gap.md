# 绩效归因 — 系统下一个增量 (2026-06-14 识别)

## 现状

v5 有五层决策数据，但没有闭环反馈。系统告诉你买什么，但从不告诉你上次为什么赢了/输了。

113 笔已完成交易，不知道：
- MACD 金叉买入的胜率 vs RSI 超卖买入的胜率
- 板块缺配驱动的买入赚钱了吗
- 哪些信号是噪音（胜率和抛硬币没区别）

## 目标

一段死代码，每次交易后自动记录：

```
买入 COHR x5 @$385 → 原因: 扫描器#3, ai板块, 动量+18, RSI=52, 放量上涨
3天后卖出 COHR x5 @$420 → PnL: +$175 (+9.1%)
对比: 同期 SPY +2.1%, 板块 +3.5%
结论: 超额+7.0%
```

100 笔后自动统计：各买因的胜率、赔率、超额收益。

## 设计原则

- 不依赖 AI 判断——纯数据记录和统计
- 脚本在每次 us_trader.py --stops 或 --execute 后自动追加记录
- 不需要实时性——cron 跑就行
- 输出可被 us_report.py 读取，注入 AI 决策上下文

## 需要的数据

| 字段 | 来源 |
|------|------|
| 买入时间 | Alpaca order filled_at |
| 买入价格 | Alpaca order filled_avg_price |
| 买入原因 | 需从扫描器/板块缺口/衰减 人工记录（最难） |
| 卖出时间/价格/原因 | Alpaca order + 信号衰减/止损触发 |
| 同期基准 | SPY/板块 ETF 同期收益 |

## 为什么现在不做

- v5 刚上线需要跑通一个完整交易周
- 买入原因记录需要改 us_trader.py 下单接口，涉及面广
- 优先级低于「让系统先稳定运行」
