# 模型定价与选择 (2026-06-10)

## 用户决策

**选定模型：mimo-v2.5-pro，按量计费，一个模型走天下。**

理由：
- 中文能力强，适合 Agent 任务
- 代码能力够用（Python + API 调用 + 数据处理）
- 按量计费与 DeepSeek 同价，但只需一个平台
- Token Plan（Lite 41亿 Credits）在全用 pro 时不够，按量更灵活

### Token Plan vs 按量计费选择

| 场景 | 推荐 |
|------|------|
| 单模型、用量大（>1亿 tokens/月） | 按量计费 |
| 多模型混合、缓存命中率高（>95%） | Token Plan |
| 用量小、固定预算 | Token Plan Lite |
