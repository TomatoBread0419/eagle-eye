# 规则失灵案例 (2026-06-17)

## 问题

用户偏好"龙头回避+投机选股"规则存在于多个位置，但**执行层全部断裂**：

| 层 | 状态 | 位置 |
|---|---|---|
| Memory | ✅ 有记录 | "龙头回避+投机选股：#1-2👑跳过选#3-5" |
| SKILL.md | ✅ 有多处 | v4.3变更、2026-06-16教训、2026-06-17偏好 |
| us_screener.py | ⚠️ 只标记不过滤 | `sector_leader`标记存在但未用于过滤 |
| Cron prompt | ❌ 缺失 | AI决策任务无"排除龙头"硬约束 |
| UNIVERSE | ❌ 缺失 | 83只全是大盘蓝筹，无中小盘成长股 |

## 当前持仓 vs 规则

```
持仓     板块排名     违反?
```

## 根因

**规则失灵 = 规则存在但不执行**

三层断裂：
1. 记忆/Skill记录了规则 → 但脚本不读这些
2. 扫描器标记了龙头 → 但不过滤
3. AI决策prompt无硬约束 → AI不知道要排除

## 修复清单

### 1. us_screener.py — 过滤逻辑

```python
# 在 buy_candidates 过滤逻辑中加入（约第636行）：
if r.get('sector_leader'):
    ok = False; reasons.append('板块龙头回避')
```

### 2. UNIVERSE — 扩充扫描池

当前83只全是大盘蓝筹。需加入投机标的：

```python
# AI基础设施
'MRVL': 'ai',      # 光模块/AI网络
'IONQ': 'ai',      # 量子计算
'SOUN': 'ai',      # 语音AI
'COHR': 'ai',      # 光子/激光

'AXTI': 'resources', # 磷化铟InP衬底
'SMCI': 'tech',    # 超微电脑
'PLTR': 'ai',      # 已在池中但波动率高
```

### 3. Cron prompt — 硬约束

在AI决策任务prompt中加入：
```
⚠️ 硬约束：禁止买入板块#1-2龙头股。扫描器输出的sector_leader=True的标的必须跳过，选#3-5成长股。
```

## 教训

**规则失灵模式**：
- 记忆/Skill是"被动注入"的，脚本/Cron是"主动执行"的
- 脚本不看记忆，只看自己的代码和配置
- Skill记录了规则不等于执行层实现了规则
- 每次新增用户偏好时，必须同时写入：①Memory ②SKILL.md ③脚本代码 ④Cron prompt

**验证方法**：
- 定期自检：列出所有用户偏好 → 检查每个偏好在执行层是否有对应实现
- 不要假设"记住了就等于做到了"
