# v5.2 事件信号修复 (2026-06-15)

## 问题

`load_sector_event_bias()` 读取 `events`（list）和 `position_impact`（dict）字段。但 `market_events_latest.json` 根本没有这两个字段。

实际 JSON 结构：
```
{
  "scan_time": "...",
  "sectors": [{ "sector": "半导体/AI", "en": [...], "zh": [...], "wsc": [...] }],
  "market_data": { "US Indices": [...], "US Stocks": [...] },
  "summary": {
    "assessments": [
      {
        "sector": "半导体/AI",          // ← 中文！
        "direction": "🟡 中性",         // 🟢利好 / 🔴利空 / 🟡中性
        "significant": true,
        "hot_events": ["war", "tariff"],
        "key_news": [...]
      }
    ]
  }
}
```

结果：`load_sector_event_bias()` 每次返回空 dict → 事件板块评分 ±3 从未生效。

## 修复

1. 读 `summary.assessments` 而非 `events`/`position_impact`
2. 中文板块名 → 英文映射（`SECTOR_CN_TO_EN`，~25条）
3. 🟡中性 + hot_events → -1 不确定性惩罚
4. 返回值从 `dict` → `(dict, list)` 元组
5. 🔴级事件输出 `critical_alerts`
6. `us_report.py` 在扫描器候选前显示事件警告
7. `us_watchlist.json` 新增两个字段

## 教训

- 数据生产者（market-event-monitor）改了输出结构，数据消费者（us_screener）没有同步更新
- JSON 字段不存在时 `data.get('events', [])` 返回空 list，不报错 → 静默失败
- 应该有集成测试：跑完扫描器后检查 `sector_bias` 是否非空（当有非中性事件时）
