# v5.0 变更记录 (2026-06-14)

## 核心变化：补齐专业交易员的决策层次

v4 有 13 维度技术分析 + AI 驱动执行，但跳过了专业交易员的前三层决策：
① 宏观环境 → ② 市场广度 → ③ 板块轮动 → ④ 个股选择

v5 补上了 ①②③，并增加了仓位科学（凯利）和出场优化（信号衰减）。

## 新增模块

### 1. macro_context.py — 宏观环境温度计
- VIX (^VIX): 恐慌指数，<15 自满 / 15-25 正常 / 25-35 恐慌 / >35 极度恐慌
- DXY (DX-Y.NYB): 美元指数，>108 强美元逆风 / <100 弱美元顺风
- 10Y-2Y利差: 倒挂=衰退预警(6-18个月领先)
- FOMC日历: 下次会议天数
- 综合判断: NORMAL/CAUTIOUS/CRISIS
- 输出: ~/stock_trader/macro_context.json
- Termux时区修复: 需要 tzdata (`pip install tzdata`)

### 2. market_breadth.py — 市场广度健康度
- 扫描83只标的+11只板块ETF
- 10线程并行，10-15秒完成
- %>MA50, %>MA200 — 多少股票在趋势之上
- 涨跌比 — 今天的内部强度
- 新高/新低 — 极端情绪检测
- 板块健康度排名 (按%>MA200)
- ETF月表现排名 — 资金流向
- 输出: ~/stock_trader/market_breadth.json
- 注意: get_daily_bars() 需要同时传 days 和 limit (>200 个交易日需要 days=300, limit=300)

### 3. us_kelly.py — 凯利仓位计算器
- 从Alpaca拉取90天订单历史
- FIFO配对买卖 → 计算胜率/赔率
- 凯利公式: f* = (bp - q) / b
- 半凯利执行 (保守)
- 约束: 1%-25% 仓位范围
- 输出: ~/stock_trader/trade_history.json
- 2026-06-14实测: 胜率45.8%, 赔率2.41, 半凯利11.7%

### 4. us_signal_decay.py — 信号衰减检测
- 检查每只持仓的买入理由是否仍成立
- RSI > 75: 过热 (warning)
- MACD 死叉: 趋势反转 (critical)
- 价格 < MA50: 中期趋势破坏 (critical)
- 价格 < MA20: 短期走弱 (warning)
- 大幅盈利 >25%: 建议缩紧止盈线 (watch)
- 输出: ~/stock_trader/signal_decay.json

### 5. us_report.py 增强

- 新增 📊 市场广度区段（含板块健康度+ETF资金流）

## 决策层次对比

### v4 (旧):
```
事件 → AI直接看个股评分 → 决定买什么
```

### v5 (新):
```
① 宏观: 现在是什么市？VIX低+DXY弱+利差正常 → NORMAL
② 广度: 这个市健康吗？63%>MA200+涨跌比1.3 → HEALTHY  
③ 凯利: 应该下多大注？胜率46%+赔率2.4 → 半凯利12%
④ 选股: 板块健康度+缺口+评分 → 选工业/能源 #3-5
⑤ 衰减: 买了之后理由变了吗？每2h自动检测
```

## 数据管线注意事项

1. **get_daily_bars limit参数**: 默认70，需要更多交易日时必须显式传 limit。MA200需要≥200个交易日≈300日历天。
2. **yfinance 从中国**: 可能被墙或超时。macro_context.py 有 FRED 公开 CSV 作为 2Y 收益率的备用数据源。
3. **tzdata**: Termux 需要 `pip install tzdata` 否则 yfinance 报 "No time zone found"。
4. **Kelly盈亏**: 累计盈亏是FIFO配对后的总和，代表"已完成交易"的盈亏，不等于账户权益变化（因为还有持仓浮亏）。
