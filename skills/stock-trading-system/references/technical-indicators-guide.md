# 技术指标实战指南

> 用真实持仓数据讲解 K线/RSI/布林带/均线。不是教科书，是交易系统每轮 cron 在算的东西。

## K线（Candlestick）

一根 K 线 = 四个价格：
```
       最高价 ← 上影线
   ┌───┐
   │   │ 实体：开盘→收盘
   └───┘
       最低价 ← 下影线
```
- 🟢 阳线 = 收盘 > 开盘（涨）
- 🔴 阴线 = 收盘 < 开盘（跌）
- 连续阳线且实体变长 → 上涨加速（接近顶部）
- 连续阴线且实体变长 → 下跌加速（接近底部）

## 均线（MA - Moving Average）

就是最近 N 天的平均价。系统用 MA5（5日均线）和 MA20（20日均线）。

**金叉/死叉：**
- MA5 > MA20 → 📈 上涨趋势（金叉）
- MA5 < MA20 → 📉 下跌趋势（死叉）

**多头排列：** 价格 > MA5 > MA20 → 强劲上涨
**空头排列：** 价格 < MA5 < MA20 → 持续下跌

## RSI（相对强弱指数）

回答：**涨过头了吗？**

```
0 ──────────── 30 ───────── 70 ──────────── 100
   超卖区（该反弹了）   正常     超买区（该回调了）
```

- RSI > 80 → 系统自动卖 50%（不是不看好，是涨太快歇口气）
- RSI < 30 → 超卖，统计上即将反弹
- 系统用 RSI(14) = 过去14天的涨跌比例

**关键：RSI 不是"买卖"信号，是"该不该追/该不该怕"信号。**

## 布林带（Bollinger Bands）

三条线：中轨 = MA20，上下轨 = MA20 ± 2倍标准差。

核心思想：**价格像被橡皮筋拴住的球。**
- 68% 时间在 ±1σ 内
- 95% 时间在 ±2σ 内（上下轨之间）
- 冲出上轨 → 橡皮筋拉太紧 → 大概率弹回来
- 跌破下轨 → 橡皮筋缩过度 → 大概率弹回去

**实战用法：**
- 突破上轨 → 警惕回调（系统收紧止损）
- 跌破下轨 → 关注反弹机会（系统标记为买入候选）

## 四条线的配合

一起看，不单独信任何一个：

| 场景 | RSI | 均线 | 布林 | 判断 |
|------|-----|------|------|------|
| 强势上涨 | >70 | 金叉 | 接近/突破上轨 | 持有但收紧止损 |
| 弱势下跌 | <30 | 死叉 | 接近/跌破下轨 | 关注反弹，等均线反转 |
| 横盘震荡 | 40-60 | 缠绕 | 中轨附近 | 等待方向选择 |
| 过热追高 | >85 | 任意 | 突破上轨 | 强烈卖出信号 |
| 超卖机会 | <25 | 任意 | 跌破下轨 | 强烈买入信号 |

## 系统里的代码

`us_trader.py` 每轮 cron 对所有持仓+候选池算这四条：

```python
closes = [b['c'] for b in bars]          # K线收盘价序列
ma5  = calc_sma(closes, 5)               # 5日均线
ma20 = calc_sma(closes, 20)              # 20日均线
rsi  = calc_rsi(closes, 14)              # 14日RSI
lower, mid, upper = calc_boll(closes, 20) # 布林带
```

买入信号 = RSI 超卖 + 价格跌破布林下轨 + 均线转多
卖出信号 = RSI 超买(>80) 或 从20日高点回撤>8%

**额外：v4 技术面快照对非持仓股票也算这四条，抓"暗流"异动。**
