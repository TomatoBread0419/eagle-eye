## 新增模块

### calibrator.py
```
输入: trade_history.json (90天交易记录) + market_env.json
输出: calibrated_params.json
校准项目:
  - sigmoid参数(k, midpoint) → 用实际score vs 涨跌拟合(scipy.optimize.curve_fit)
  - ATR→赔率映射 → 用实际盈亏比
  - 止损分档 → 用被止损标的后续走势反推(假止损率>40%→放宽1%)
  - 板块加分 → 用板块平均盈亏映射到±3
  - 评分权重 → 用top10胜率验证预测力(discrimination指标)
  - 市场状态 → VIX+广度+涨跌比→trending/volatile/crisis/quiet
```

### compliance_audit.py
```
输入: 20条用户偏好(硬编码在脚本中) + 脚本源码
输出: compliance_report.json (合规率 + 每条状态)
检查方法: 正则匹配脚本内容中是否有对应实现
频率: 每周六06:10
```

### us_pending_replacements.json
```
sell→buy配对的中间状态文件
止损/止盈卖出时自动写入 → AI决策层读取后1小时内安排替代买入
包含: symbol, reason, qty, price, timestamp, replace_by(1h过期)
```
