# A股自动化交易方案（2026-06 调研）

## 核心结论

**A股没有开放 REST API（不像 Alpaca），所有实盘量化方案都依赖 Windows 桌面客户端。**

用户场景：Hermes Agent 跑在小米Pad5 (Termux)，有 Windows 电脑但不想24小时开着（功耗高/电费贵）。

## 方案对比

### 券商系（需开户 + Windows）

| 平台 | 背景 | 资金门槛 | 说明 |
|------|------|---------|------|
| **QMT (迅投)** | 各券商合作 | 0-50万 | 最主流，支持 Python (xtquant)，国金/国盛/华鑫等 |
| **PTrade** | 恒生电子 | 50万+ | 机构级，个人通过券商申请 |
| **华泰 MATIC** | 华泰证券 | 需华泰开户 | 华泰自有 |
| **国信 TradeStation** | 国信证券 | 需国信开户 | 基于 TradeStation |

### 第三方量化平台（云端）

| 平台 | Python SDK | 实盘 | Termux 可用 |
|------|:---:|:---:|:---:|
| **掘金量化 (MyQuant)** | ✅ | ✅ 对接券商 | SDK 可装，云端执行 |
| **聚宽 (JoinQuant)** | ✅ | ✅ 对接券商 | SDK 可装，云端执行 |
| **米筐 (RiceQuant)** | ✅ | ✅ 对接券商 | SDK 可装 |
| **果仁网** | Web | ✅ | 浏览器访问 |
| **万矿 (WindQuant)** | ✅ | ✅ | 贵，万得旗下 |

### 数据 API（纯 Termux 可用）

| 平台 | 说明 | Termux |
|------|------|:---:|
| **Tushare** | 免费 A 股数据，积分制 | ✅ pip install |
| **AKShare** | 开源免费，数据全 | ✅ pip install |

## 推荐架构：Termux Agent + 云 Windows QMT

```
小米Pad5 (Termux, 24h在线)     云Windows服务器（~30-50元/月）
┌─────────────────────┐       ┌──────────────────────┐
│ Hermes Agent        │ HTTP  │  QMT + xtquant       │
│ 策略/信号生成        │──────→│  Flask/FastAPI 桥接   │
│ 数据采集(AKShare)    │       │  券商下单执行          │
└─────────────────────┘       └──────────────────────┘
```

### 为什么用云服务器而非本地 Windows
- 本地 Windows 24h 功耗 100-200W → 电费 40-80元/月
- 云 Windows 轻量服务器 30-50元/月，更便宜且 99.9% 在线
- 无断电/断网风险

### 实施步骤
1. 券商开户，申请 QMT 权限（推荐国金/华鑫，门槛低）
2. 云服务器装 QMT + xtquant
3. 写 HTTP 桥接层（Flask/FastAPI，暴露下单接口）
4. Termux Agent 通过 HTTP POST 发送交易信号
5. 云端 QMT 执行下单

## 监管注意

- 证监会对程序化交易有报备要求
- 个人散户目前管得松但趋势是收紧
- 模拟盘无限制，实盘注意合规
