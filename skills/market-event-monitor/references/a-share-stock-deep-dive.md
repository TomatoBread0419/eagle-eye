# A 股个股深度分析与筛选

## 触发场景

| 模式 | 用户说 | 场景特征 |
|:----:|--------|----------|
| **A: 个股分析** | 「XXX可以买吗」「看看XXX」「XXX怎么样」 | 用户报了一只A股，要买卖建议 |
| **B: 扫描推荐** | 「看几只潜力股」「推荐几个标的」「现在什么好买」 | 用户要筛选+推荐 |

### ⚡ 模式切换：A→B 的常见路径

用户常从单只分析**自然过渡**到批量推荐：

```
用户：三峡能源可以买吗？   → 模式A 个股分析
用户：新潮能源可以买吗？   → 模式A 个股分析（第二只）
用户：好多                 → 🟡 信号！用户对A股有兴趣了
用户：看看A股比较有潜力的三只 → 切换到模式B 扫描推荐
```

**关键信号词**：用户看完个股分析后说「好多」「还有吗」「再看看」「推荐几只」「有潜力的」→ **立即切换模式B**，不需要等用户明确说"帮我扫描"。

### ⚡ 模式间关系

与 `stock-surge-reverse-investigation.md` 的区别：该流程只对**正在暴涨**的个股做逆向催化挖掘。本流程覆盖所有形态（上涨/下跌/横盘）的买入可行性分析 + 批量扫描推荐。

## 模式 A：单只个股可买性分析（六步法）

### Step 1: 确认股票代码 + 板块归属

A 股代码前缀：
- `sh` = 上海主板（600/601/603/605/688 科创板）
- `sz` = 深圳主板（000/001/002/003）+ 创业板（300/301）

常见代码查询：
```bash
# 上海：sh600xxx / sh688xxx
# 深圳：sz000xxx / sz002xxx / sz300xxx
```

### Step 2: 获取实时行情（qt.gtimg.cn）

**⚠️ 关键坑：字段索引**

qt.gtimg.cn 返回 `~` 分隔的字符串。常用字段（0-indexed）：

| 索引 | 字段 | 说明 |
|:---:|------|------|
| 1 | 名称 | |
| 2 | 代码 | |
| **3** | **最新价** | |
| 4 | 昨收 | |
| 5 | 今开 | |
| 6 | 成交量(手) | |
| 31 | 涨跌额 | |
| **32** | **涨跌幅%** | ✅ 这才是正确的涨跌幅 |
| 33 | 最高价 | |
| 34 | 最低价 | |
| 36 | 换手率% | |
| 38 | 市盈率(动) | 注意：数值需要除以某系数，不是原始值（见下文PE说明） |
| 44 | 总市值 | (字段索引视行情软件版本可能有偏移) |

**❗ 常见错误**：初学者容易取 `parts[5]`（今开价）当涨跌幅，或取错行。**涨跌幅在 idx32，不是 idx5。**

```python
# ✅ 正确解析
parts = line.split('~')
name = parts[1]
price = parts[3]
pct = parts[32]  # 这才是涨跌幅%
high = parts[33]
low = parts[34]
```

**PE 注意**：idx38 的 PE 值在不同的 qt 版本中含义不同。有些版本返回的是"动态市盈率/某系数"，不要直接当真实PE用。更可靠的做法：
- 用总市值/净利润估算（如果财务数据可获取）
- 或直接写行业平均PE做参考，标注"偏贵/合理/低估"

### Step 3: 拉取 K 线看趋势

```bash
curl -s "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600905,day,,,20,qfq"
# 返回 JSON: data.sh600905.qfqday = [[date, open, close, high, low, volume], ...]
# sh=上海，sz=深圳
```

**分析要点**：
- **趋势方向**：近5日/10日/20日收盘价走势（上升/下降/横盘）
- **加速/减速**：最近3天的涨幅占比前10天涨幅的比例
- **成交量变化**：上涨放量/缩量？下跌放量/缩量？
- **关键支撑/阻力位**：前低、前高、整数关口

**常见形态判断（含量化阈值）**：

| 形态 | 量化条件 | 含义 |
|:----:|----------|------|
| 缩量阴跌 | 连跌≥5天 + 近3日日均换手<0.3% + 量价同步萎缩 | 没人接盘，阴跌不止，不要抄底 |
| 缩量上涨 | 连涨≥3天 + 换手<0.5% + 成交量低于20日均量 | 抛压轻但承接弱，涨不踏实 |
| 放量突破 | 突破前高 + 当日量>20日均量×2 | 真突破，可跟进 |
| 冲高回落（射击之星） | 日内高点→收盘回撤>3% + 放量 | 主力出货/短期见顶，不追 |
| 跳空高开 | 开盘>前收3%+且不回补 | 消息驱动，需确认催化强度 |
| 温和走强 | 5日涨幅3~10% + 换手0.5~2% + 量价配合 | 有趋势但没透支，最佳候选 |
| 几日暴涨 | 5日涨幅>15%（如新潮能源+24%） | 短期过热，不追，等回调|

### Step 4: 同板块对比

拉同板块其他龙头股做横向比较，判断个股是**领涨**还是**跟涨**。

```bash
# 例如分析钨板块：
curl -s "https://qt.gtimg.cn/q=sh600549,sz000657,sz002378"
# 厦门钨业(600549) + 中钨高新(000657) + 章源钨业(002378)
```

**判断标准**：
- 板块普涨 + 该股领涨 → 🟢 龙头，强势
- 板块普涨 + 该股跟涨 → 🟡 跟随，有板块贝塔但无个股阿尔法
- 板块普跌 + 该股抗跌 → 🟢 相对强势，可能有独立逻辑
- 板块普跌 + 该股领跌 → 🔴 弱势，回避

### Step 5: 搜索新闻/催化

按优先级使用：
1. **wallstreetcn** — 综合快讯，对大盘/热门板块覆盖好
2. **Sogou 微信** — 深度分析/行业报告，对冷门题材覆盖好

```bash
# wallstreetcn — 拉文章列表后用关键词过滤
curl -s "https://api-one.wallstcn.com/apiv1/content/articles?channel=global-channel&limit=30" | python3 -c "
import json, sys
items = json.load(sys.stdin).get('data',{}).get('items',[])
for i in items:
    if '三峽' in i.get('title','') or '新能源' in i.get('title',''):
        print(i['title'])
"

# Sogou 微信
curl -s -L -A 'Mozilla/5.0' 'https://weixin.sogou.com/weixin?type=2&query=三峽能源+600905+2026&ie=utf8'
```

**⚠️ 注意**：Sogou 微信最近（2026-06-24 实测）返回空结果，可能是反爬或改版。wallstreetcn 对冷门题材覆盖薄。如果都搜不到，如实说"未找到明确催化"——**不要编造新闻**。

**⚠️ K线数据中的停牌缺口检测（2026-06-24实战）**：qt.gtimg.cn K线接口返回的是**连续交易日**数据。当相邻两根K线日期不连续（如6/18→6/23，中间缺少6/19+6/22），说明该股票在此期间**可能停牌**。停牌后复牌常伴随跳空高开/低开。遇到缺口应：
1. 记录停牌区间和复牌后跳空幅度
2. 搜索停牌原因（wallstreetcn/搜狗搜「代码 停牌」）
3. 复牌后暴涨（如新潮能源从4.91→5.40跳空+10%）→ 催化已兑现，不追

### Step 6: 综合输出（分析模板）

```
## 📊 XXX（代码）现状

| 项目 | 数据 |
|------|------|
| 现价 | X.XX（今日+/-X.XX%）|
| 近X日 | X.XX → X.XX（+/-X.X%）|
| 换手率 | X.XX% |
| 总市值 | ~X亿 |

### 📉 技术面
[K线趋势描述 + 关键价位的点评]

### 基本面/催化
[公司做什么 + 行业地位 + 近期催化剂]

### 判断
**短期（1-4周）：[建议]**
[X条理由]

**中长期（3-6月）：[建议]**
[X条理由]

### 总结
[一句话结论 + 如果要买的位置建议]
```

**判断规则**：
- 缩量阴跌（如三峡能源）→ 不建议，等放量企稳
- 几日暴涨+冲高回落（如新潮能源 +24%）→ 不建议追
- 温和上涨+放量健康 → 可考虑，设好止损
- 横盘缩量+有催化 → 关注，等放量信号
- **明确找不到催化信息的暴涨 → 纯情绪/游资，不追**

## 模式 B：扫描推荐潜力股

当用户要求"推荐几只/看看潜力股"时，执行以下流程：

### B1: 扫描当前市场热点（系统化漏斗）

从全市场逐层缩小范围，而非随机选板块：

```bash
# 1. 大盘指数判断风格方向
curl -s "https://qt.gtimg.cn/q=s_sh000001,s_sz399001,s_sz399006,s_sz399986,s_sz399997,s_sh000933"
# 关注：哪个指数最强（创业板 vs 上证 vs 深证）？
# 关注：哪些行业在跌（资金流出方向）？

# 2. 看 wallstreetcn 今日要闻标题
curl -s "https://api-one.wallstcn.com/apiv1/content/articles?channel=a-stock-channel&limit=5"
```

### B2: 锁定热点板块

从大盘+新闻交叉验证，选择 2-3 个当前有资金流入的板块：
- **热点板块**：涨跌前列的行业（医药+1.66%、半导体上涨等）
- **政策催化板块**：近期有利好的方向（如 AI 算力国产化、创新药出海）
- **周期反转板块**：从底部回暖的方向

### B3: 选板块内龙头/弹性标的

每个板块选 3-4 只候选，拉实时行情对比：

```bash
# 同一板块的候选一起拉，快速对比
curl -s "https://qt.gtimg.cn/q=sh603019,sh688041,sz300308,sh688256"
```

### B4: 拉 K 线过滤

排除：
- 已经暴涨过的（5日+15%以上且无回调） → 追高风险大
- 明显下跌趋势中（连续新低） → 没见底
- 换手率极低（<0.3%） → 没人关注

保留：
- 温和上涨（5日+3~10%）→ 有趋势但没透支
- 横盘整理末端 → 等突破
- 回调到支撑位 → 性价比较好

### B5: 交叉验证推荐

选 3 只，覆盖**不同赛道**（不推同板块同质化的）。按**性价比排序**而非确定性排序：

| 优先级 | 特征 | 评价 |
|:------:|------|------|
| 🥇 | 涨幅最克制（5日+3~8%）+ 逻辑硬 + 门槛低 | **性价比最高 → 首选推荐** |
| 🥈 | 确定性最强但已涨一段（5日+10~15%） | 可配，但提醒追高风险 |
| 🥉 | 催化清晰但还没热（5日+<3%） | 潜伏型，需耐心 |

输出格式：

```
## 🥇 第1只：XXX（代码）— [赛道]

| 项目 | 数据 |
| :--- | :--- |
| 现价 | X.XX（今日+/-X.XX%）|
| 近5日 | X.XX → X.XX（**+X.X%**）|

[符合"保留"标准的具体表现]

**为什么看好：**
- [核心逻辑1]
- [核心逻辑2]

**风险：** [主要风险提醒]
**排序：** [按性价比排列三只]
```

**选股核心原则**（来自2026-06-24实战）：
1. **涨得最少的同赛道的优先** — 还在相对低位才有空间
2. **赛道不重叠** — 三只股票分属不同行业（半导体设备 / AI算力 / 汽车电子 而非 三个都是光伏）
3. **追涨的不推** — 已经暴涨24%的再推荐=害人
4. **每只都标风险** — 没有无风险的推荐

## 已知局限（2026-06-25）

1. **Sogou 微信搜索近期返回空结果**（2026-06-24 实测：所有关键词均无返回）。疑似反爬机制升级或改版。不可用时直接说明"未找到相关新闻"
2. **qt.gtimg.cn 的 PE 字段（idx38）存疑** — 2026-06-24 实测部分股票返回异常值（0.17/0.21 等非正常PE）。不建议将 idx38 作为权威PE使用
3. **DNS 劫持干扰** — qt.gtimg.cn 和 web.ifzq.gtimg.cn 在中国移动网络下经常被劫持到 198.18.0.x。依赖 `dns-hijack-fix` skill 的 `sitecustomize.py` 自动 DoH 回退。如果 DoH 回退失败（极慢或空数据），告诉用户"当前网络环境无法获取数据"
4. **本流程不覆盖美股** — A 股的 sh/sz 前缀规则不适用于美股。美股分析见鹰眼系统的扫描器 + market-event-monitor 库存
5. **用户的市场主要在美股（Alpaca）** — A股分析仅限建议，没有交易管线。输出最后必须标注这一点
